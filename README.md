# 🍽️ Layali Hadramout Restaurant Website

## 🌐 Overview
**Layali Hadramout** is a professional website for a restaurant, designed to showcase the restaurant's products, chefs, events, and other offerings.  

Users can place orders directly from the website by adding desired items to an order, reviewing it, and sending the completed order via **WhatsApp** to the restaurant for fast processing.  

The system also includes a **full admin dashboard**, allowing the restaurant to manage categories, menu items, events, bookings, and website settings easily.

**Live Website:** [https://layalihadramout.com/](https://layalihadramout.com/)

---

## 🚀 Features

### 🌟 Frontend Features
- **Restaurant Overview** — Clear presentation of the restaurant, chefs, and services.  
- **Menu Display** — Showcase all food items organized by categories for easy navigation.  
- **Order System** — Users can select items, review orders, and send them via WhatsApp.  
- **Bookings** — Users can request table reservations through the website.  
- **Events Section** — Display upcoming events with details and images.  
- **Contact Section** — "Contact Us" section allows users to send messages directly to the restaurant.  
- **Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices.  
- **Modern UI** — Attractive and user-friendly interface.

---

### 🏢 Admin Dashboard
- **Full Admin Dashboard** — Complete control over all website content.  
- **Menu Management** — Add, edit, and delete categories and menu items.  
- **Event Management** — Add, edit, and delete restaurant events.  
- **Booking Management** — Manage reservations made by users.  
- **Order Management** — Track orders sent via the website.  
- **Contact Messages** — View messages sent from the "Contact Us" section.  
- **Restaurant Settings** — Update images, contact info, and other display settings.  
- **User-Friendly Interface** — Designed for non-technical users to manage content efficiently.
